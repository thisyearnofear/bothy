# EDTH asset research plan

Date: 2026-10-03
POC: Bothy team lead
TL;DR: Source the smallest set of credible, reusable inputs needed for a live dependency explanation and defensible submission. No credential storage, paid integrations, public uploads, or buyer outreach.

## Questions

- What does the supplied deep graph actually model, and which data/license boundaries apply?
- Which bounded query can expose platform/component/material relationships without inventing a real defence BOM?
- Which official gallium sources support supply-risk context separately from synthetic graph evidence?
- What identity/browser components can support a disposable demo without weakening authority checks?
- Which presentation assets can be reused legally and quickly?

## Approach

Retrieve official dataset documentation, USGS gallium summary, EU raw-material classification, TuringDB version/query guidance, and identity/browser project documentation. Preserve fetched source artifacts in the research inventory. Prefer existing graph stores and current tests over new ingestion or identity integrations under deadline pressure.

## Deliverables

A prioritized asset manifest with provenance/license constraints, direct acquisition links, exact next implementation work, and explicit blocked requirements. Distinguish sourced inputs from downloaded assets, live-tested queries, and customer-validated facts. Actual event resources require authenticated access; do not infer sponsor rules from the starter.
